# Agent 任务工作区指南

## 定位和前提

假设 Agent 具备自己的 workspace 和文件读写工具。对于跨服务、多轮或可中断任务，Agent 可以在 **Agent 自己的 workspace** 中保存最少量的任务记忆，在上下文缩短或对话恢复后继续工作。

任务实例属于 Agent 的运行时数据，不应写进 `huaweicloud-skill` 源码目录，也不应提交到 Skill 仓库。Skill 只提供建议语义和可选模板。

## 什么时候记录

建议建立持久 task 记录的情形：

- 用户目标预计需要多轮完成或会被持续修改；
- 一个目标涉及多个服务、多个阶段或异步任务；
- 任务包含真实副作用、等待、失败恢复或后续业务验收；
- 任务可能被别的请求打断，之后需要准确恢复。

简单、一次性的只读查询可以不创建 task 目录；如果记录，一段短摘要通常足够。

## 每个任务使用独立标识

开始一个新任务时，Agent 应确定一个在当前 workspace 内稳定且唯一的 `task_id`。它应：

- 在同一任务的后续对话中保持不变；
- 不依赖易变化的标题，不依赖 PID；
- 不包含 AK/SK、账号、手机号等敏感信息；
- 避免 `/`、`..` 等会改变目录语义的字符。

推荐的轻量目录如下：

```text
tasks/<task_id>/
├── task.md
├── context.jsonl      # 可选：少量高影响事实或观测
├── progress.md
└── artifacts/         # 可选：必要的计划、摘要或验证产物
```

这不是强制文件布局。Agent 可以合并 `task.md` 和 `progress.md`，可以增加适合自身运行时的 JSON、数据库索引或其他文件，也可以只保留一个短文件。关键是不同任务不串线，并能恢复最小必要语义。

## 最小可恢复语义

跨轮次恢复时，记录至少应让 Agent 找回：

- task ID 和当前目标；
- 当前仍有效的关键约束与用户授权边界；
- 期望结果和必要的完成证据；
- 最近重要进展、变化、失败或未知项；
- 当前方案、待决定事项和下一步。

可从以下模板开始，并按任务复杂度删减或改写：

- `templates/task.md`
- `templates/progress.md`

模板不是要求 Agent 填满字段，也不要求生成 TaskContract 或 TaskPlan 数据结构。

## 按需保存高影响事实

`context.jsonl` 仅用于值得跨轮保留、并可能影响后续决策的信息。例如：

```json
{"fact":"目标必须运行 Java 服务","value":true,"source":"user","observed_at":"2026-08-01T10:00:00+08:00","scope":"task","note":"取代初始静态站候选"}
```

字段可按 Agent 的工具和任务情况调整。普通聊天内容无需逐条结构化；云侧实时状态也不应被永久当作最新事实。

## 多轮对话如何更新

| 对话变化 | 建议处理 |
| --- | --- |
| 用户补充要求 | 合并到当前目标或关键约束，并记录对现有方案的影响 |
| 用户修改或撤销要求 | 保留最新有效要求，简要说明旧方案为何失效 |
| 用户追加同一目标的操作 | 继续同一 `task_id`，更新进展、证据和下一步 |
| 用户插入无关请求 | 建立另一个 task 或明确作为临时请求，避免污染原任务 |
| 用户要求继续旧任务 | 先定位 task，再从记录恢复；高影响实时事实按需重新查询 |
| 无法确认是否同一任务 | 若误合并风险较低可先说明假设；风险较高则向用户澄清 |

Agent 仍可根据现场情况改变服务、工具、参数和执行方式。任务记录描述“当前知道什么、正在追求什么”，不规定执行步骤。

## 恢复和收尾

恢复任务时，可检查 task ID、最新目标、未完成项、最近证据以及可能过期的观测，再自主决定需要重新查询还是直接继续。这是恢复提示，不定义状态机或固定操作序列。

任务结束时：

- 写明完成、部分完成、未知或阻塞部分及其依据；
- 不再需要的临时大文件按 Agent 的 workspace 策略清理；
- 是否归档由 Agent 运行时和用户需求决定。

## 安全边界

- 不在 task 文件或 `artifacts/` 保存 AK/SK、API Key、私钥、完整 token 或其他凭据。
- 对命令输出和资源信息做必要脱敏，只保留恢复任务所需内容。
- task 记录不是审计日志，也不能替代执行前的用户确认、实时权限检查或云侧回读。
- 不把另一个 task 的事实、授权或资源范围默认为当前任务可用。
